## 🏨 Hotel Nebula
  
📘 Projeto acadêmico desenvolvido em Kotlin que simula um sistema de gerenciamento de hotel via terminal, com foco na aplicação prática de conceitos fundamentais de programação.

### 🧠 Sobre
  
O projeto consiste na análise e evolução de um código base previamente fornecido, com o objetivo de aplicar melhorias estruturais e funcionais por meio do pensamento crítico. A proposta envolve a identificação de limitações no sistema original e a implementação de soluções mais organizadas, modulares e eficientes.

### ⚙️ Funcionalidades
- 👤 Cadastrar hóspedes
- 🔍 Pesquisar hóspedes
- 📋 Listar hóspedes
- ❌ Remover hóspedes
